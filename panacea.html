Пространство для внутреннего диалога

Panacea — это не чатбот и не гороскоп. Это среда, где можно поговорить с AI-моделью, специализирующейся именно в той области, которая нужна сейчас: разобрать сон, прочитать карту Таро, понять кармический сценарий или просто выговориться психологу, у которого есть время.

Работает как Telegram Mini App, как сайт и как PWA — одна кодовая база. Войти можно через Google или Apple, либо как гость — в этом случае история хранится в localStorage и очищается через 24 часа. Проект условно-бесплатный: базовые функции доступны всем, расширенные — по подписке.

Интерфейс

Одна карточка — весь интерфейс

Вся навигация построена на одном экране: это физическая карточка с двумя сторонами. Лицевая — анкета перед сеансом. Обратная — архив всех прошлых разговоров. Переключение происходит по клику на угол карточки: карточка плавно переворачивается, как игральная.

Никакого меню, никаких вкладок. Одна карточка → флип → архив. Это намеренное решение: меньше интерфейса — больше фокуса на самом разговоре.

Из архива доступен чат поддержки, скачивание PDF-протоколов сеансов и выход из аккаунта. Всё — в рамках того же единого экрана. Переход в чат происходит после анкеты: выбор запроса, состояния и нескольких параметров — и загрузочный экран с каруселью цитат запускает сеанс.

Модели

Шесть AI-моделей с личностями

Каждая модель — не просто набор промптов. У каждой есть имя, стиль речи, область знаний и характер. Они обучены на реальной литературе: юнгианская психология, нарративная терапия, классическая астрология, Таро Уэйта, нумерология Пифагора, тексты по регрессионной терапии. Датасет формировался вручную — из первоисточников, не из Википедии.

Таро
Тара
Символический язык карт. Говорит образами, не советами. Помогает увидеть скрытое за поверхностью событий.
Кармология
Карма
Читает повторяющиеся сценарии и незакрытые циклы. Опирается на концепции индийской философии — без эзотерического флёра.
Астрология
Астра
Натальные карты, транзиты, планетарные циклы. Объясняет механику, а не предсказывает будущее.
Регрессология
Ева
Работает с памятью и корнями притяжений. Мягкий проводник — не давит, не интерпретирует за тебя.
Психология
Психея
Юнгианский анализ и нарративная терапия. Слышит не только слова, но и то, что стоит за ними.
Нумерология
Гера
Числа, даты, имена. Расшифровывает числовой код — без мистики, с логикой системы.
Обучение

RAG, индексация и реальная литература

Модели работают не просто на системных промптах — они подключены к индексированной базе знаний через RAG (Retrieval-Augmented Generation). При каждом запросе система ищет релевантные фрагменты из датасета и передаёт их в контекст модели вместе с вопросом пользователя.

Датасет из первоисточников
Юнг, Уэйт, Пифагорейская нумерология, Бхагавад-гита, Ньютон-Хоуэлл — реальная литература, не агрегаторы
Векторная индексация
Тексты разбиты на чанки, векторизованы и хранятся в индексе для семантического поиска
Контекст = личность + знание + запрос
Каждый запрос обогащается релевантными фрагментами базы и передаётся в модель с характером конкретного персонажа
Контент внутри сеанса
Модель может прислать тест, притчу или карточку-вложение — не случайно, а по контексту разговора
RAG — упрощённая схема 
// 1. Векторизуем запрос пользователя
const queryVector = await embed(userMessage);

// 2. Ищем ближайшие чанки в индексе базы знаний
const context = await vectorDB.search(queryVector, topK: 5);

// 3. Строим промпт: личность модели + знание + вопрос
const prompt = buildPrompt(modelPersonality, context, userMessage);

// 4. Отправляем в LLM — модель отвечает с опорой на источник
const response = await llm.complete(prompt);
Panacea Plus

Премиум-функции

Подписка Panacea Plus доступна за Telegram Stars или криптовалюту — без карты, без банка. Открывает расширенные режимы и снимает ограничения. Функции постоянно развиваются: к эндпоинтам подключаются API лучших сервисов — лучшая озвучка, точнее распознавание речи, новые модели.

Оракул
Анализирует запрос мета-моделью и автоматически выбирает нужную из шести
Консилиум
Все шесть отвечают одновременно — параллельные запросы, шесть точек зрения на один вопрос
Голосовой ввод и озвучивание
Whisper (Groq) распознаёт речь, TTS озвучивает ответы моделей
PDF-протокол сеанса
AI генерирует саммари на стороне клиента: вопрос, обсуждение, вывод

Telegram Stars не требуют карты — достаточно внутреннего баланса. Крипто-опция для тех, кто за пределами Telegram.

Архитектура

Как устроено внутри

Одна кодовая база — три канала. Telegram Mini App открывается кнопкой из бота, сайт работает в браузере, PWA устанавливается на рабочий стол. История сеансов хранится в облаке для авторизованных пользователей, гостевой режим очищается через 24 часа.

Оракул — выбор модели 
// Мета-модель анализирует запрос и выбирает одну из шести
// Temperature: 0.3 — точный выбор, а не творческий
// Max tokens: 50 — только название модели в ответе
const chosen = await selectModel(query, { temp: 0.3, max: 50 });
// Выбранная модель отвечает, подписывает ответ: «— Тара»
