Ферма 3D принтеров под одной крышей

Prism — это веб-приложение для управления фермой 3D принтеров Bambu Lab. Загружай файлы одной кнопкой на все принтеры одновременно, отслеживай статусы через MQTT, контролируй процесс печати. Всё работает в локальной сети без зависимости от интернета.

Приложение написано на Python Flask с поддержкой параллельных загрузок через FTPS (implicit TLS, порт 990), асинхронной обработки и real-time мониторинга. ThreadPoolExecutor обеспечивает одновременную работу с несколькими принтерами. Интерфейс адаптивен для мобильных устройств.

Интерфейс

Простота и скорость

Дашборд показывает список всех принтеров и их текущее состояние. Каждый принтер отображает данные в реальном времени: статус печати, процент завершения, температура, объём используемой памяти. Загрузка файлов происходит по FTPS с проверкой формата и кешированием списков файлов на принтерах.

Масштабируемость: приложение способно управлять фермой из десятков принтеров без потери производительности. ThreadPoolExecutor позволяет загружать файлы на всех принтерах параллельно, экономя время.

Как это работает

Приложение использует Implicit FTPS для безопасной загрузки файлов (порт 990), который используют принтеры Bambu Lab. MQTT позволяет получать обновления статусов в реальном времени без постоянных опросов. SSDP мультикаст используется для автоматического обнаружения принтеров в локальной сети.

    futures = []
    for printer in printers:
        future = executor.submit(upload_file_ftp, printer, file_path)
        futures.append((printer, future))

Статусы заданий

Отслеживание в реальном времени

Каждое задание загрузки получает уникальный ID и отслеживается через in-memory хранилище с блокировкой потоков. Пользователь видит статусы в реальном времени через WebSocket или REST API. Поддерживаются статусы: ожидание, загрузка, успешно, ошибка.

Конфигурация принтеров хранится в printers.json и загружается при старте приложения. Пользователь может добавлять/удалять принтеры через веб-интерфейс, и данные сохраняются между сеансами.

Кто это использует

Prism активно используют крупные фермы 3D печати по всему миру. От малых студий (5–10 принтеров) до промышленных ферм (50+ машин). Каждый решает одну проблему: быстро загрузить файлы на все принтеры без облака и привязки к подписке.

Разработчики Bambu Lab видят value в таких проектах и поддерживают их. API открыт, документация обновляется, и никто не будет блокировать приложение за использование официального API.
