В разработке

Всё для спорта в одном приложении

MSE — это веб-платформа для спортсменов и тренеров. Трекинг тренировок, питание с автоматическим расчётом макронутриентов, Instagram-интеграция для визуального прогресса, AI-ассистент для консультаций, система донатов и экзамены для тренеров. Всё в одном интерфейсе, с синхронизацией через Firebase и адаптивным дизайном для мобильных устройств.

Работает как веб-приложение и как PWA — можно установить на рабочий стол и использовать как нативное приложение. Авторизация через Google и Apple, реалтайм-синхронизация данных, анимации GSAP и Lottie для плавного UX.

Интерфейс

Дизайн, который не отвлекает

Интерфейс построен на принципе "меньше элементов — больше функций". Главный экран — дашборд с быстрым доступом ко всем модулям: тренировки, питание, прогресс, чат с AI, Instagram, донаты. Каждая секция открывается в отдельной панели без перезагрузки страницы. Анимации плавные, навигация интуитивная, весь интерфейс адаптирован под мобильные устройства.

Графитовая цветовая схема — без ярких акцентов, чтобы не отвлекать от контента. Белые элементы на тёмном фоне, минимализм в типографике, GSAP-анимации для плавных переходов.

Все формы адаптивны: добавление тренировки, запись питания, загрузка фото в Instagram — всё работает в реалтайме, с валидацией и автосохранением. При потере соединения данные сохраняются локально и синхронизируются при восстановлении сети.

Функции

Трекинг тренировок и питания

Спортсмен записывает тренировки: упражнения, подходы, повторения, вес. Система автоматически строит графики прогресса и показывает динамику по каждому упражнению. Питание работает так же: вводишь продукты, система считает калории, белки, жиры, углеводы — всё автоматически. Можно задать цель (набор массы, сушка, поддержание) — система подстроит рекомендации.

Запись упражнений, подходов, весов. Автоматическое построение графиков прогресса

Загрузка фото прогресса напрямую из приложения, автопостинг с хештегами
AI-ассистент
Консультации по тренировкам, питанию, восстановлению. GPT-4 с датасетом спортивной литературы
Система донатов
Поддержка тренеров от подписчиков, интеграция с платёжными системами
Экзамены для тренеров
Проверка знаний тренеров, выдача сертификатов, рейтинг

Firebase Realtime Database позволяет видеть изменения в реалтайме: если тренер обновил программу, спортсмен видит это мгновенно. Без перезагрузки, без задержек.

Архитектура

Как устроено внутри

Frontend на React + Vite — быстрая сборка, hot reload, минимальный bundle size. Backend на Firebase: аутентификация, Realtime Database для синхронизации, Cloud Functions для бизнес-логики. AI-ассистент работает через OpenAI API с кастомными промптами и датасетом спортивной литературы. Instagram-интеграция через официальный API, донаты через Stripe.

JavaScript 
// Реалтайм-синхронизация тренировок через Firebase
const workoutsRef = ref(db, `users/${userId}/workouts`);
onValue(workoutsRef, (snapshot) => {
  const data = snapshot.val();
  setWorkouts(data); // Обновление UI автоматически
});
